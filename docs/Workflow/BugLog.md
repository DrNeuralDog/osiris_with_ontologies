# Известные неисправленные проблемы

## BUG-001 — locale-зависимое форматирование расстояний в тесте

- Обнаружение: 2026-09-21; общий модуль `src/lib/geo.test.ts`.
- Источник: исходное сообщение пользователя, воспроизведено агентом до и после реализации ontology.
- Шаги: Windows/PowerShell, `npm test`; сценарий `formatting > switches units at sensible thresholds`.
- Фактически: `4 200 km`; тест ожидает `4,200 km`.
- Ожидается: согласованное поведение форматирования и locale-independent проверка либо явно выбранная locale.
- Влияние: один baseline failure общего набора; ontology-тесты проходят. Отложено по указанию пользователя: не относится к ontology.

## BUG-002 — внешний OpenSanctions CSV обрывается при загрузке

- Обнаружение: 2026-09-21; intel / внешний источник OpenSanctions OFAC SDN.
- Источник: наблюдение агента, воспроизведено в Node внутри Docker и Windows curl.
- Шаги: запустить `docker compose up -d --build`; проверить `docker compose logs osiris-intel` и `http://localhost:4000/health`. Независимое воспроизведение: загрузка `https://data.opensanctions.org/datasets/latest/us_ofac_sdn/targets.simple.csv` обычным curl с `-L --max-time 35`.
- Фактически: HTTP 200 после allowlisted redirect, затем `terminated UND_ERR_SOCKET other side closed`; curl получил 10 136 из 7 556 118 байт и timeout. `sanctions_entries=0`. Отключение сжатия в диагностическом запросе не помогло.
- Ожидается: полный CSV и заполненный индекс, с последующим сохранением совпавших объектов/связей в PostgreSQL.
- Влияние: живое обогащение санкциями недоступно; нет оснований делать вывод об отсутствии санкций. Остальные источники/граф/БД работают. UI предупреждает, loader сохраняет предыдущий индекс при сбое и повторяет загрузку.
- Отсрочка: причина внешнего сетевого обрыва не установлена; код загрузчика, redirects/allowlist и сохранение stale index проверены fixture-тестом. Нужна повторная проверка после восстановления загрузки источника.

## BUG-003 — timeout Carto при холодном запуске карты

- Обнаружение: 2026-09-21; существующие `api/proxy-tiles` / `OsirisMap`.
- Источник: наблюдение агента во временном frontend-контейнере UI smoke на порту 3001.
- Шаги: отдельный контейнер из production image с пустым runtime cache; открыть главную страницу. В трёх попытках запрос style.json Carto через существующий tile proxy завершился HTTP 500 / timeout.
- Фактически: панели доступны, но карта остаётся пустой после отказа начального style. При успешной загрузке основного стека на 3000 карта, исторический track и фокусировка работают; это не воспроизводится на каждом запуске.
- Ожидается: понятное сообщение о недоступности basemap и управляемый повтор загрузки без потери состояния исследования.
- Влияние: временная внешняя недоступность Carto блокирует карту при холодном старте. Регрессия intelligence layer не установлена, tile proxy не изменялся. Отложено как отдельная задача устойчивости существующей карты; основной стек проверен с успешно загруженной картой.
